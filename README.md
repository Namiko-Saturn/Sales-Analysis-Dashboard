# Sales-Analysis-Dashboard
Sales analysis dashboard developed using microsoft excel
### Sales Analysis Dashboard

Project Overview

This project presents an interactive Sales Analysis Dashboard developed using Microsoft Excel.

The dashboard transforms raw sales data into meaningful visual insights, providing an overview of sales performance and helping identify trends, patterns, and areas of strong performance.

Project Objective

The objective of this project was to analyze sales data and develop an interactive Excel dashboard that can be used to monitor business performance and support data-driven decision-making.

Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Excel Formulas
* Data Cleaning
* Data Analysis
* Data Visualization

Key Areas of Analysis

The analysis covers key sales performance areas, including:

* Total Sales
* Revenue
* Profit
* Units Sold
* Product Performance
* Regional Performance
* Sales Trends
* Customer/Order Analysis

Dashboard Features

The dashboard includes:

* KPI cards for key performance indicators
* Interactive charts and visualizations
* Sales performance analysis
* Product comparisons
* Regional analysis
* Trend analysis
* Filters for exploring different segments of the data

Dashboard Preview

Key Insights

The dashboard provides a visual overview of sales performance across different products, regions, and time periods.

It allows users to compare performance between categories, identify sales trends, and examine areas contributing to overall business performance.
